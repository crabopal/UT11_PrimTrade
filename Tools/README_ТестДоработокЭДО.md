# Тест доработок ЭДО без подписи

Файл: **`Tools/ТестДоработокЭДО.epf`** (исходники — `Tools/ТестДоработокЭДО_src/`).

В конфигурации также есть одноимённая обработка (`DataProcessor.ТестДоработокЭДО`) — тот же код, если ветка уже загружена в базу.

## Как открыть (.epf)

1. В 1С (УТ): **Файл** → **Открыть** → `Tools/ТестДоработокЭДО.epf`.
2. Выбрать документ-основание: счёт-фактура выданный, реализация или корректировка реализации.
3. Формат: УПД 5.03 или УКД 2020.
4. Нажать **Открыть просмотр**.
5. В типовой форме включить **Отображать дополнительную информацию**.

Подпись, оператор ЭДО и приглашение контрагента не нужны.

## Пересборка .epf

Нужна база с конфигурацией УТ (типы `DocumentRef.*`), пустая ИБ не подойдёт:

```text
1cv8 DESIGNER /S "localhost\UT_PrimTrade" /DisableStartupDialogs /DisableStartupMessages
  /LoadExternalDataProcessorOrReportFromFiles
  Tools\ТестДоработокЭДО_src\ТестДоработокЭДО.xml
  Tools\ТестДоработокЭДО.epf
```

## Что проверить

| Сценарий | Данные в учёте | Ожидание в просмотре |
|---|---|---|
| Винлаб УПД | В наименовании контрагента есть «Винлаб»; у сделки в комментарии номер заказа с `;`; есть штрихкоды | `номер_заказа`, `номер_накладной`, в строках `штрихкод` |
| Первые семейные | Партнёр или его родитель содержит «Первые семейные» | `штрихкод` в строках |
| РЕМИ / ЭКОНОМЫЧ | Партнёр/группа содержит «РЕМИ» или «ЭКОНОМЫЧ» | заказ, накладная, при наличии EDI — GLN; в строках код материала, позиция, штрихкод |
| Прочий контрагент | Обычный клиент | этих ключей нет |

Внизу формы обработки выводится текстовая диагностика доп. полей — удобно сверить, если в печатной форме доп. информация выключена.
